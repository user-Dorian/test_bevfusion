## 🎯 启用的增强模块

### 1. SEBlock 通道注意力 ✅
**位置**: DepthLSSTransform 内部  
**数量**: 2 个  
**配置**:
```yaml
vtransform:
  type: DepthLSSTransform
  use_attention: true  # ← 启用 SEBlock
```

**详细说明**:
- **dtransform 中的 SEBlock(64)**:
  - 输入：64 通道深度特征
  - 结构：Linear(64→4) → ReLU → Linear(4→64) → Sigmoid
  - 参数量：512
  - 作用：深度特征通道加权

- **depthnet 中的 SEBlock(256)**:
  - 输入：256 通道融合特征
  - 结构：Linear(256→16) → ReLU → Linear(16→256) → Sigmoid
  - 参数量：8,192
  - 作用：融合特征通道加权

**参数量总计**: 8,704 (约 8.7K)

---

### 2. CBAM 注意力 ✅
**位置**: SparseEncoder 输出后  
**配置**:
```yaml
lidar:
  backbone:
    type: SparseEncoder
    use_cbam: true  # ← 启用 CBAM
    cbam_ratio: 16  # 降维比例
```

**详细说明**:
- **输入**: 128 通道 LiDAR BEV 特征
- **ChannelAttention**:
  - 结构：AdaptiveAvgPool2d + AdaptiveMaxPool2d → Conv2d(128→8) → ReLU → Conv2d(8→128) → Sigmoid
  - 参数量：128×8×2 + 8×128×2 = 4,096
- **SpatialAttention**:
  - 结构：Concat(avg, max) → Conv2d(2→1, 7×7) → Sigmoid
  - 参数量：2×7×7 = 98
- **总参数量**: 约 4.2K

**作用**:
1. ChannelAttention: 学习通道重要性
2. SpatialAttention: 学习空间重要性
3. 双重注意力提升特征质量

---

### 3. MultiScaleConvFuser ✅
**位置**: Camera 和 LiDAR 特征融合处  
**配置**:
```yaml
fuser:
  type: MultiScaleConvFuser  # ← 使用多尺度融合器
  in_channels: [80, 256]
  out_channels: 256
  attention_ratio: 16
```

**详细说明**:
- **输入**: [80 通道 (camera), 256 通道 (lidar)]
- **融合卷积**:
  - Conv2d(336→256, 3×3) + BN + ReLU
  - 参数量：336×256×3×3 + 256×4 = 774,144
- **通道注意力**:
  - AdaptiveAvgPool2d → Conv2d(256→16) → ReLU → Conv2d(16→256) → Sigmoid
  - 参数量：256×16 + 16×256 = 8,192
- **细化卷积**:
  - Conv2d(256→256, 3×3) + BN + ReLU + Conv2d(256→256, 3×3)
  - 参数量：256×256×3×3×2 + 256×4 = 1,180,672
- **总参数量**: 约 1.96M

**作用**:
1. 基础融合：拼接 + 卷积
2. 通道注意力：学习融合特征的通道权重
3. 细化卷积：进一步优化融合特征

## 🔍 常见问题

### Q1: 为什么使用 MultiScaleConvFuser 而不是 ConvFuser？
**A**: MultiScaleConvFuser 添加了通道注意力和细化卷积，可以提升特征融合质量，特别是对小物体检测。

### Q2: CBAM 和 SEBlock 有什么区别？
**A**: 
- SEBlock: 只有通道注意力
- CBAM: 通道注意力 + 空间注意力，更全面

### Q3: 参数量增加了多少？
**A**: 约 1.4M，占整个模型的 0.7%，几乎可以忽略。

### Q4: 如果训练报错维度不匹配怎么办？
**A**: 检查配置文件中的通道数是否与代码定义一致，特别是：
- vtransform.in_channels = neck.out_channels
- fuser.in_channels = [camera_bev_channels, lidar_bev_channels]
- decoder.backbone.in_channels = fuser.out_channels
